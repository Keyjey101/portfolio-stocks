# Фронтенд v4.2 «Грация» — анализ стека и changelog

Дата: 2026-08-27 · ветка `frontend-v4.2` (от master 4c705f0).

## 1. Анализ: нужен ли фреймворк (React/Vue/…)

Вопрос: «будет ли красивее и проще с компонентным фреймворком?» — проверен
по коду и ограничениям развёртывания. **Ответ: нет, миграция не подтверждена.**

| Фактор | Реальность проекта |
|---|---|
| Модель взаимодействия | 5 страниц, каждая = «fetch JSON → рендер строкой»; клиентского состояния почти нет (последний ответ API и есть состояние) — главная ценность React (локальный стейт + реконсиляция) здесь не востребована |
| Компонентность | Уже есть: каждый `renderXxx()` — чистая функция данных в HTML; дублирование утилит убрано общими `auth.js`/`fx.js` |
| Развёртывание | Прод без билд-степа: rsync `public/` + systemd; VPS без исходящих соединений к npm. React = обязать прод запускать сборку или возить `dist/` — новая точка отказа |
| Зависимости | Сейчас ноль npm-пакетов на фронтенд; фреймворк = node_modules, lockfile, совместимости версий |
| Риск | ~2400 строк бой-кода на живом продукте; «без ошибок с первого раза» при миграции всех 5 страниц недостижимо |
| Красота | Определяется CSS/DOM-хореографией, а не слоем рендера; v4 «серебряные приборы» целиком реализуем (и реализован) на платформе |

Вывод: остаёмся на zero-dependency ванилле и берём «технологичность» из
современной веб-платформы — View Transitions, `@property`-анимации цветов,
IntersectionObserver, интерполяция размеров. Всё progressive enhancement:
в старых браузерах деградирует до сегодняшнего поведения.

## 2. Что добавлено (дизайн-язык не меняется — серебро/бронза/mono)

**Движение и цвет**
- Переходы между страницами: `@view-transition {navigation:auto}` — кроссфейд
  с микро-масштабом, плавучий остров шапки «переезжает» между страницами
  (`view-transition-name:island`).
- Смена вердикта/настроения теперь перетекает, а не мигает: `--amb-a/b/c`,
  `--vc`, `--cc` зарегистрированы через `@property` и анимируются переходом.
- Стеклянный блик на приборах (`.bez:hover .core::after`) — ловит свет под
  курсором, только opacity.
- `<details>` (помощь, таблицы лаборатории) раскрывается по высоте:
  `::details-content` + `interpolate-size:allow-keywords`.

**Главная (/)**
- Одометр главного числа: при обновлении цифры прокручиваются посимвольно
  (справа налево, направление по знаку изменения), смена разряда — кроссфейд.
- Счётчики карточек после первого рендера едут от прошлого значения к новому,
  а не с нуля.
- Спарклайны и годовой график S&P: плавные кривые (Catmull-Rom → Безье) с
  прорисовкой штриха при первом показе + точка «сейчас».
- Донат: сегмент и строка легенды подсвечивают друг друга, прочие гаснут.
- Вердикт не изменился — прибор не перерисовывается и не мигает; изменился —
  мягкое перевсплытие заголовка и точек.
- «Оседание» (`body.settled`): автообновление раз в 90 с больше не проигрывает
  входные анимации заново — меняются только значения.
- Spotlight-поиск: под полем — тикеры (цена · день), страницы и действия;
  ↑/↓/Enter, Esc; Enter по тикеру прыгает к строке и подсвечивает её бронзой.
  Живой фильтр таблиц сохранён.

**Лаборатория (/lab)**
- Скелетоны-шиммеры у считающихся секций вместо голого «Загружаем…».
- Секции ниже первого экрана появляются по скролу (IO + геометрическая
  страховка), а не все сразу при загрузке.
- Бронзовый волосок прогресса чтения сверху (`#sprog`).

**Оценка акций и сканер**
- Чипы фаз под прогресс-трубой (шаги SSE / фазы скана) — загораются по факту.
- Секции результата появляются каскадом (`FX.stagger`), спарклайн выручки
  тоже плавный.

**Везде**
- Волосок прогресса чтения, стоп-страховки `setTimeout` для rAF/IO в
  замороженных фоновой вкладкой сценариях (контент не застревает невидимым).
- Мягкая 404 в языке дизайна (`public/404.html`); `/api/*` на неизвестный
  путь отвечает JSON.

## 3. Файлы

- `public/fx.js` — новый общий рантайм движения (smoothPath, drawIn, odo,
  io, sprog, stagger, skel); подключён на всех страницах после auth.js.
- `public/style.css` — блок v4.2 (+переход `#ringFg`, `scroll-margin` строк,
  транзишены `.dseg`).
- `public/app.js`, `public/analysis.js`, `public/scanner.js` — интеграция.
- `public/index.html`, `lab.html`, `analysis.html`, `scanner.html` — script,
  скелетоны, контейнеры фаз.
- `src/server.js` — 404-fallback (страницы → 404.html, API → JSON).

Правила сохранены: движение только transform/opacity (исключения —
фоновые переливы скелетона и прорисовка штриха), единая кривая
`cubic-bezier(.32,.72,0,1)`, `prefers-reduced-motion` гасит всё,
`prefers-reduced-transparency` — блик и backdrop.
