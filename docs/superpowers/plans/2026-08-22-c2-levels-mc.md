# Часть C2 — калибровка уровней (#5) и Монте-Карло (#4): план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GARCH-волатильность и вероятности касания T-уровней; Монте-Карло 10 лет с HMM-режимами, блочным бутстрапом и довнесениями $250/мес; оба блока — в `/lab`.

**Architecture:** численные методы в `src/math/timeseries.js` (Нелдер-Мид, GARCH(1,1), барьерная вероятность) и `src/math/hmm.js` (гауссов HMM, scaled forward-backward); подсистемы в `src/lab/levels.js` и `src/lab/mc.js`; симуляции MC — в `worker_threads` (`src/workers/mc-worker.js`); кэши: уровни 24 ч, MC 7 дней.

**Tech Stack:** Node 18+, без зависимостей, node:test.

**Spec:** `docs/superpowers/specs/2026-08-21-part-c-lab-design.md`, раздел 5.

## Global Constraints

- Node ≥ 18.14, npm-зависимости не вводим.
- Параметры MC из `.env`: `MC_MONTHLY_USD` (дефолт 250), `MC_YEARS` (дефолт 10), опц. `MC_TARGET_USD` — env-переменная имеет приоритет над файлом.
- Довнесения зачисляются в конце месяца; просадка считается по месячным срезам (задокументировано в UI).
- Дрейф в pTouch — историческая средняя ×0,5 (шринк к нулю), помечена как прокси.
- Все тесты — `node:test` в `test/`, прогон `npm test`.

### Task 2: `stats.js` — normCdf и lcg

**Files:** Modify `src/math/stats.js`, `test/stats.test.js`.

**Interfaces:** `normCdf(x)` — Φ(x), A&S 7.1.26, |ε|<1.5e-7; `lcg(seed)` — детерминированный ГПСЧ uniform [0,1). Тесты: Φ(0)=0.5, Φ(1.96)≈0.975, симметрия, Φ(3)≈0.99865.

### Task 3: `timeseries.js` — Нелдер-Мид

**Files:** Create `src/math/timeseries.js`, `test/nm.test.js`.

**Interfaces:** `nelderMead(f, x0, {maxIter=800, tol=1e-9}) → {x, fx}`; стартовый симплекс — шаг 0.1·|xᵢ| (или 0.05 при нуле) по каждой оси. Тесты: Розенброк → [1,1]±1e-2; квадратичная → минимум.

### Task 4: `timeseries.js` — GARCH(1,1)

**Files:** Modify `src/math/timeseries.js`, `test/garch.test.js`.

**Interfaces:** `fitGARCH(rets) → {omega, alpha, beta, ll, sig2next, muRet}`: доходности центрируются; параметры через преобразование ω=e^u, α=0.98·σ(a), β=(1−α)·σ(b) (стационарность гарантирована); MLE Нелдером, 3 старта (α,β) = (0.08,0.90)/(0.15,0.80)/(0.05,0.70). `garchForecast(fit, horizonDays) → {avgVar, varAt, longRunVar}`: v_h = ω̄ + (α+β)^{h−1}(sig2next − ω̄). Тест: симулированная GARCH(1.5e-6, 0.08, 0.90), 4000 дней — α,β восстанавливаются ±0.05; прогноз при большом горизонте → безусловная σ.

### Task 5: `timeseries.js` — pTouch

**Files:** Modify `src/math/timeseries.js`, `test/ptouch.test.js`.

**Interfaces:** `pTouch(S0, target, muAnn, sigAnn, Tyears)`: барьер ниже цены, формула отражения для X=νt+σW, ν=μ−σ²/2, b=ln(target/S0): P = Φ((b−νT)/(σ√T)) + e^{2νb/σ²}·Φ((b+νT)/(σ√T)); target ≥ S0 → 1. Тест: кросс-проверка против посевного MC (20k путей), расхождение < 0.02 на трёх случаях.

### Task 6: `src/lab/levels.js` — calibrateLevels

**Files:** Create `src/lab/levels.js`, `test/levels.test.js`.

**Interfaces:** `calibrateLevels(closes, lv, horizonYr=1) → {px, sigAnn, muAnn, levels:[{v,p}], fantasy, merge:[[a,b]], waitCost, fit}`: σ год = √(252·avgVar по GARCH-прогнозу); μ = историческая×252×0.5; fantasy = P(T3)<0.05; merge — пары уровней ближе 1σ годовой в $; waitCost = (1−P(T1))·μ·H·px (прокси). Тест: синтетический GBM σ=0.25 — P средних уровней в (0.05,0.95), далёкий уровень → fantasy, близкие уровни → merge.

### Task 7: `runLevels` + роут

**Files:** Modify `src/lab/levels.js`, `src/lab/factors.js` (loadPrices принимает range), `src/server.js`; Test `test/levels.run.test.js`.

**Interfaces:** `loadPrices(tickers, range='1y')`; `runLevels({force, positionsLoader, cacheName='levels'})` — позиции с реальными lv (≠999), заливка 2y, кэш 24 ч, inflight-dedup; `GET /api/lab/levels[?force=1]`. Тест: мок fetch (520 точек), lv [380,355,340] → 3 уровня с P, повтор из кэша без сети.

### Task 8: `src/math/hmm.js` — гауссов HMM

**Files:** Create `src/math/hmm.js`, `test/hmm.test.js`.

**Interfaces:** `fitGaussianHMM(X, k, {maxIter=120, tol=1e-4}) → {k, pi, A, means, vars, ll, states[], bic}`: диагональная ковариация, scaled forward-backward (Рабинер), init квантилями признака 0; `selectHMM(X, ks=[2,3]) → {best, models}`, BIC = −2ll + p·ln n, p = k(k−1)+(k−1)+2kd. Тест: двухрежимный синтез (N(0,1)/N(4,1), P(stay)=0.97) — метки совпадают >95%, диагональ A >0.9, selectHMM выбирает k=2.

### Task 9: `src/lab/mc.js` — simulateMC

**Files:** Create `src/lab/mc.js`, `test/mc.sim.test.js`.

**Interfaces:** `matrixPower(M, p)`; `simulateMC({pools, A, pi, years, monthlyUsd, startValue, paths, seed}) → {terminal:{p5,p25,p50,p75,p95}, terminalSorted, maxDD, yearly:[quantile per year], totalContrib}`: месячный шаг = A²¹, блочный бутстрап 21 дня из пула состояния, довнесение в конце месяца, DD по месячным срезам, детерминизм от seed. Тесты: один пул μ_d=2e-4, σ≈1e-8 (почти детерминированный) — медиана ≈ start·e^{μ·2520} ±2%; тот же seed → идентичный результат; довнесения ×2 растят медиану ≈ на FV аннуитета.

**Interfaces:** `buildMCData({positionsLoader})` — 2y: позиции + ^GSPC/^VIX/^TNX, выравнивание (alignPrices), дневные доходности портфеля по текущим весам, признаки [VIX, ΔTNX20, rSPX20] стандартизуются, selectHMM → pools/A/π (стационарное через степенную итерацию), stateStats в сырых единицах; `runMC({force, inline, paths, seed})` — env-параметры (250/10/цель), три симуляции (×0.5/×1/×2) в worker_threads (или inline для тестов), кэш 'mc' 7 дней, targetProb = доля траекторий ≥ цели. Роут `GET /api/lab/mc[?force=1]`. Планировщик: прогрев MC через 90 с + раз в 7 дней. Тест: синтетика 2y → k, pools, base.terminal.p50 > 0; кэш-повтор без сети.
