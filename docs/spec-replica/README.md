# Техническая спецификация: платформа фундаментальной оценки акций

Спека для полного воспроизведения в другом проекте двух фич системы stock-llm (GMYRYA):

1. **Анализ отдельного тикера** — определение переоценённости/недооценённости, справедливой
   стоимости (мульти-методный DCF-движок), инвестиционного вердикта и уверенности.
2. **Секторный сканер** — пакетный анализ всех компаний выбранного сектора с фильтрами
   (capitalization, объём, стоки-лист, top-N), прескринингом, глубоким обогащением,
   детекцией value-trap'ов, новостным радаром и LLM-советником.

## Ключевые принципы (обязательны к сохранению)

1. **Математика детерминирована, LLM только интерпретирует.** Справедливая стоимость,
   MoS, скор и вердикт считаются кодом по формулам из `03`/`04`. LLM-агенты генерируют
   только нарративы и качественные оценки (ров/бизнес-скор/риск-скор), причём их
   арифметические выходы проходят sanity-цепочку. Это делает результат
   воспроизводимым и дешёвым в отладке.
2. **«Честная неопределённость» (honest uncertainty gates).** Если данных мало или
   методы расходятся — система не выдаёт точечную оценку: показывает диапазон,
   помечает `no_estimate` / `low_reliability` и ставит вердикт `No Decision`
   вместо выдуманной точности.
3. **Graceful degradation.** Каждый агент имеет фоллбек; отказ LLM ≠ отказ анализа.
   Число упавших агентов (`agents_failed`) влияет на вердикт и уверенность, а на
   уровне бэкенда — на возврат кредитов и кэширование.
4. **Защита от value-trap'ов.** Дешёвизна сама по себе не сигнал: качество, цикличность,
   пик маржи, red flags и новости демотируют скор и вердикт (см. `06`, §5–8).
5. **Прогресс и устойчивость стрима.** Анализ идёт минуты; SSE с heartbeats,
   гибридный (время + шаги) прогресс-бар и бесплатное восстановление результата
   после обрыва связи (`/result`, 204-поллинг).

## Глоссарий

- **FV (fair value)** — справедливая стоимость на акцию (base/bear/bull).
- **MoS (margin of safety)** — `(FV_base − цена) / цена × 100%`.
- **EPV** — earnings power value (Greenwald): стоимость текущей нормализованной прибыли без роста.
- **Verdict** — итоговое решение: `Strong Buy / Buy / Hold / Avoid / No Decision`.
- **Прескрин** — быстрый проход по вселенной тикеров по 2–3 полям (P/E, ROE, сектор…).
- **Enrichment** — глубокий проход по top-N кандидатам (полная отчётность + LLM).
- **Value trap** — акция дешёвая из-за деградации бизнеса, а не из-за недооценки.
