# 11. Реализация в этом репозитории

Спека (01–10) описывает стек оригинала (Python FastAPI + Express + Vue).
Разрешённая замена («замены допустимы при сохранении контрактов из 08», 01 §1.5)
здесь использована целиком: всё работает в **одном Node.js-процессе** существующего
терминала, без новых зависимостей. Контракты 08 (SSE-кадры, `/result`-204,
`/scan` → `/status` → `/results`, camelCase внешнего API, TTL кэшей) сохранены.

## Отступления от буквы спеки (осознанные)

- **Кредиты** — `NoopBilling`: личный инструмент, списаний нет; ветвление по
  `agents_failed` сохранено (возврат → «не кэшировать при ≥2»).
- **13F-институционалы** не снимаются: `institutional_changes` честно пустой.
- **Russell-2000** снимок не ведётся: единственная вселенная — курируемый
  список ~527 тикеров (`src/equity/universe.js`), обновляется руками.
- **Лок анализа** — in-process Map (один процесс); файловый лок не нужен.
- **SSE `/scan/:id/progress`** не реализован (улучшение 10 §11): поллинг `/status`.
- Дивидендный deep-пайплайн упрощён в решении: композит из качества/payout/
  cut-risk/YoC по правилам (пороги 75/60/40), LLM-агенты — как в §4.9.

## Запуск и проверка

```
node dashboard.js                 # страницы: /stock-analysis, /market-scanner (владелец)
node --test                       # 236 тестов, из них 40 — блок оценки
```

Тесты движка — на синтетике без сети (`test/intrinsic|decision|financial|scanner.test.js`),
интеграционные — на фикстурном fetch и фейковом LLM (`test/equity.run.test.js`),
включая гейт страниц паролем через `server.handle()`.

Деплой: изменений nginx не нужно (те же `/` и `/api/`); на сервере —
`git pull && systemctl restart portfolio-stocks`. Новые env не обязательны:
`ZAI_API_KEY` уже есть, `NEWSAPI_KEY` опционален, rf для WACC берётся из кэша
FRED-полосы (нет ключа — дефолт 4,3%).
